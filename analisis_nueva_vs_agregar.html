📋 Análisis: "Nueva canción" vs "+ Agregar canción"

¿Son el mismo cuadro? ¿Dónde se usan? ¿Se pueden optimizar?

🎯 Respuesta Rápida

"Nueva canción" y "+ Agregar canción" son cuadros DIFERENTES."

  • "Nueva canción" → Abre el #editor (mismo en todos lados) ✅ Reutilizado
  • "+ Agregar canción" → Abre el #agregar (es solo para buscar y seleccionar) ❌ Único

🆕 "Nueva canción" - Crea una CANCIÓN NUEVA

Cuando tocás "+ Nueva canción", se abre el editor (#editor) en modo "crear".

1
Usuario toca "+ Nueva canción"
Aparece en: Canciones (pie) o Panel Agregar (pie)
2
Se invoca: abrirEditor("nueva")
Función única para ambos botones
3
Se abre #editor
Campos vacíos: nombre, tono, BPM, letra y acordes
4
Usuario completa la canción
Escribe nombre, tono opcional, BPM opcional, letra y acordes
5
Toca "Guardar"
Se invoca guardarEditor() → se agrega a catálogo
¿Se reutiliza el mismo cuadro #editor?
✅ SÍ - "+ Nueva" en Canciones (línea 1707)
✅ SÍ - "+ Nueva" en Panel Agregar (línea 2070)
Resultado: Ambos botones abren el MISMO #editor

➕ "+ Agregar canción" - Busca y AGREGA al evento

Cuando tocás "+ Agregar canción", se abre un panel de búsqueda (#agregar) para seleccionar canciones existentes.

1
Usuario toca "+ Agregar canción"
Aparece en: Evento (pie) o Lector de canción (pie)
2
Se invoca: abrirAgregar()
Función única para ambos botones
3
Se abre #agregar
Buscador + lista de canciones con botones "+" para agregar
4
Usuario busca o toca "+"
Filtra por título/tono/letra, o suma directamente
5
Canción se agrega a la lista del evento
Se guarda en Firestore: reuniones/{id}.ids[]
¿Se reutiliza el panel #agregar?
❌ NO - Es SOLO para agregar a evento (líneas 1857, 2040, 2047, 2688)
Situación: #agregar es específico de este flujo, no se reutiliza en otro contexto

📊 Comparativa: ¿Cuál es cada cuadro?

Botón Función Abre Aparece en ¿Reutilizado?
+ Nueva canción Crear nueva #editor Canciones, Panel Agregar ✅ SÍ (2 lugares)
+ Agregar canción Buscar y sumar #agregar Evento, Lector ❌ NO (único)
Editar canción Modificar existente #editor Menú Catálogo, Menú Evento ✅ SÍ (mismo que Nueva)

🔄 Análisis de Reutilización

El #editor se usa de 3 formas:

1. Crear nueva canción
abrirEditor("nueva")
Campos vacíos, botón eliminar oculto
2. Editar canción existente
abrirEditor(idCancion)
Campos llenos con datos, botón eliminar visible
3. Es compartido en ambos modos
La misma vista (#editor) maneja crear y editar
Esto está BIEN - es un patrón común

El #agregar es único:

Panel de búsqueda y selección
Solo se abre cuando querés agregar canciones a un evento
Es específico, no hay duplicación

✅ Conclusión

La situación es mejor de lo que parece:

  • ✅ "Nueva" ya está unificada: El mismo abrirEditor("nueva") se usa en Canciones y Panel Agregar
  • ✅ "Editar" usa lo mismo: El #editor maneja ambos modos (crear y editar)
  • ✅ "Agregar" es diferente a propósito: #agregar es para BUSCAR, no para editar
  • ✅ No hay duplicación real: Cada cuadro tiene su propósito

Recomendación: No es prioridad tocar esto. Enfocate en las 8 acciones repetidas del diagrama anterior (Editar contextos, Cerrar, Guardar, Menús) que sí tienen código duplicado.

Si quieres refactorizar igual, hacerlo como parte de la unificación de Editar Canción/Evento (podrías pasar el tipo como parámetro). Pero no es urgente.
