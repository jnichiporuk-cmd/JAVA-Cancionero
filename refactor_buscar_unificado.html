🔍 Refactor: Búsqueda Unificada

Centralizar la lógica de filtrado para que un cambio afecte todos los buscadores

❌ El Problema

Tienes dos buscadores que hacen lo MISMO pero están en código separado:

Lugar Input Placeholder Función Dónde filtra
Pestaña Canciones id="buscar" "Buscar por título, letra, tono o BPM" pintarCatalogo() Línea 1710-1716
Panel Agregar id="ag-buscar" "Buscar por título, letra, tono o BPM" pintarAgregar() Línea 2072-2075
Problema 1: Placeholder duplicado
Cuando pediste que agregara "letra" al placeholder, tuviste que pedir dos cambios (uno en cada lugar).
Problema 2: Lógica duplicada pero inconsistente
// En Canciones - SÍ busca en letra
return s.bloques.some(b => b.t === "l" && b.v.toLowerCase().includes(q));

// En Agregar - NO busca en letra
// (falta esta línea completamente)
Problema 3: Cambios futuros = múltiples ediciones
Si mañana quieres agregar búsqueda por fecha o por autor, tienes que tocar 2 funciones y mantener ambas sincronizadas.

✅ La Solución: Función Centralizada

Crear una sola función que concentre toda la lógica de búsqueda:

// Nueva función centralizada
function filtrarCanciones(query, catalogo = CATALOGO) {
  const q = query.trim().toLowerCase();

  if (!q) return catalogo;  // Sin query, devuelve todo

  return catalogo.filter(s => {
    // Buscar en nombre
    if (s.nombre.toLowerCase().includes(q)) return true;

    // Buscar en tono (búsqueda exacta: "G" ≠ "Sol")
    if ((s.tono || "").toLowerCase() === q) return true;

    // Buscar en letra (cualquier bloque de tipo "l")
    if (s.bloques.some(b => b.t === "l" && b.v.toLowerCase().includes(q))) {
      return true;
    }

    // Más criterios van acá (fecha, autor, etc.)

    return false;
  });
}
Ventaja 1: Un solo lugar donde filtra
Toda la lógica de búsqueda está en una función. Cambios futuros = editar aquí.
Ventaja 2: Reutilizable en cualquier lado
Si mañana quieres un buscador en otra pantalla, llamas filtrarCanciones(q) y listo.
Ventaja 3: Consistencia garantizada
Ambos buscadores usan los MISMOS criterios, no hay sorpresas.
