🎯 Propuesta: Historial en Evento + Compartir Canciones

Análisis de cambios arquitectónicos y de UX propuestos

1️⃣ Mover Historial dentro de Evento

Cambio propuesto

Hoy: Historial es una pestaña separada (Canciones | Historial | Evento | Transmisión)

Propuesta: Historial como menú dentro de Evento
En la línea del nombre del evento, agregar un botón "⋮" con opciones:

Comportamiento según estado:

❌ ANTES: Sin evento seleccionado
┌─────────────────────────┐ │ Historial │ │ │ │ • Reunión 1 (Nov 15) │ │ • Reunión 2 (Nov 8) │ │ • Reunión 3 (Oct 22) │ │ │ │ + Nuevo evento │ └─────────────────────────┘
✅ PROPUESTA: Sin evento seleccionado
┌─────────────────────────┐ │ 🎵 CANCIONERO v246 ⋮ │ │ Seleccionar evento │ │ o crear nuevo │ │ │ │ Canciones │ │ (Catálogo completo) │ └─────────────────────────┘ Menú ⋮: ├─ Historial │ └─ Ver reuniones │ anteriores └─ + Crear nuevo evento
❌ ANTES: Con evento seleccionado
┌─────────────────────────┐ │ PRUEBA DE EVENTO │ │ │ │ 1. CANCIÓN 1 │ │ 2. CANCIÓN 2 │ │ 3. CANCIÓN 3 │ │ │ │ + Agregar canción │ │ Transmitir │ └─────────────────────────┘
✅ PROPUESTA: Con evento seleccionado
┌─────────────────────────┐ │ 🎵 PRUEBA DE EVENTO ⋮ │ │ Jun 06/09/25 - 19:00 │ │ │ │ 1. CANCIÓN 1 │ │ 2. CANCIÓN 2 │ │ 3. CANCIÓN 3 │ │ │ │ + Agregar canción │ │ Transmitir │ └─────────────────────────┘ Menú ⋮: ├─ Ver historial │ (Reuniones anteriores) └─ + Crear nuevo evento

Implicaciones de código:

Cambios necesarios:
  • Pestaña "Historial" desaparece (ya no es página principal)
  • Crear menú desplegable en encabezado Evento
  • Menú tiene 2 opciones: "Ver historial" y "+ Crear nuevo"
  • "Ver historial" abre un panel/modal dentro de Evento (reutiliza renderGuardadas)
  • "+ Crear nuevo" abre diálogo de nueva reunión (ya existe)
  • Cambiar navegación: Canciones | Evento | Transmisión (sin Historial)

Ventajas:

Agrupa conceptos: "evento" incluye "crear nuevo" + "historial"
Menos pestañas en la barra, más limpio visualmente
Flujo lógico: entra a Evento → necesitas historial → está ahí
Sin evento: muestra opciones claras (crear o usar una guardada)

Desventajas:

Requiere acceder a menú para ver historial (un click más que ahora)
Si hay muchas reuniones, el panel modal podría ser estrecho

2️⃣ Agregar "Compartir" en menú de canciones

Cambio propuesto

En los 3 puntitos (⋮) de cada canción, agregar opción "Compartir"

Permitir enviar:

  • 📱 WhatsApp — Link + nombre de canción
  • 📧 Email — Link + metadata
  • 📋 Copiar enlace — Al portapapeles
  • 📲 Compartir nativa — Si existe Web Share API
❌ ANTES: Menú de canción
Menú ⋮ en canción: ├─ Editar ├─ Eliminar └─ (nada más)
✅ PROPUESTA: Menú extendido
Menú ⋮ en canción: ├─ Editar ├─ Eliminar ├─ ───────── └─ Compartir ├─ WhatsApp ├─ Email ├─ Copiar enlace └─ Más opciones

Datos a compartir:

const urlCompartir = `${window.location.origin}?cancion=${idCancion}&tono=${tono}`; const texto = `${nombre} - ${tono || 'Original'} (${bpm || '—'} BPM)`; WhatsApp: → https://wa.me/?text=${encodeURIComponent(texto + ' ' + urlCompartir)} Email: → mailto:?subject=${encodeURIComponent(texto)}&body=${encodeURIComponent(urlCompartir)} Copiar: → clipboard.writeText(urlCompartir) Web Share API: → navigator.share({ title: texto, url: urlCompartir })

Flujo de usuario:

1 Usuario toca ⋮ en una canción
2 Aparece menú con "Compartir"
3 Usuario elige "WhatsApp" (o Email, etc.)
4 Se abre WhatsApp con el link pre-rellenado
5 Usuario envía mensaje a grupo/contacto

Implicaciones de código:

Cambios necesarios:
  • Agregar opción "Compartir" en menús existentes (3 lugares: Catálogo, Evento, Reunión)
  • Crear función compartirCancion(cancion) que muestre submenu
  • Crear URLs de compartir para cada plataforma
  • Usar Web Share API si está disponible (fallback manual)
  • Pedir permiso para portapapeles (Clipboard API)

Ventajas:

Aumenta viralidad / difusión de canciones
Usuarios pueden compartir una canción sin describir a mano
Link con metadata permite abrir la canción directamente en tono compartido

Desventajas:

Requiere URL shareable + parámetros (cancion + tono)
Necesita que la app esté publicada en URL pública (ya está en GitHub Pages ✅)
Clipboard API requiere HTTPS (ya funciona ✅)

🛠️ Resumen Técnico

Cambio Complejidad Afecta a... Nuevas funciones
Historial en Evento Media Navegación, encabezado Evento, renderGuardadas mostrarMenuEvento(), mostrarHistorialEnModal()
Compartir canción Baja Menús (3 lugares), funciones de render compartirCancion(), generarURLCompartir()

Orden recomendado:

1 Agregar "Compartir" (más simple, independiente)
2 Mover Historial (requiere refactor de navegación)

✅ Propuesta Final

¿Querés que implementemos estos dos cambios?

Ambos aplican el patrón que ya aprendiste: reutilizar funciones (renderGuardadas para historial modal, mostrarMenu para opciones de compartir). Son cambios arquitectónicos que mejoran UX sin romper lo existente.

Tiempo estimado: 2-3 horas para ambos (con tests incluidos)
